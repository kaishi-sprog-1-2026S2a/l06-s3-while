## デバッガで処理の流れを追ってみる

tasks.joson, launch.json は用意されています。

以下の手順で、プログラムの処理の流れと変数の値を確認してください。

### while

1. while_test.c を開く
2. コンパイル Ctrl+Shift+B
3. デバッグビューに切り替える
4. ブレークポイントを設定する 5行目の ```int i = 0;```
5. デバッグ開始 F5
6. F10で進めながら、処理の流れや変数の値を確認

### do while

1. do_while_test.c を開く
2. (コンパイル Ctrl+Shift+B) whileと同時にコンパイル済み
3. デバッグビューに切り替える
4. ブレークポイントを設定する 5行目の ```int i = 0;```
5. デバッグ開始 F5
6. F10で進めながら、処理の流れや変数の値を確認
